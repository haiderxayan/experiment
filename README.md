# Unfinished: Book Website

A modern, responsive website for "Unfinished: Notes on Designing Experience in a World That Never Stops Changing" by Haider Ali.

## About

This website serves as the digital home for a living book about designing experiences that evolve with people, systems, and time. The site itself embodies the book's philosophy of iterative design and continuous evolution.

## Features

- **Modern, Clean Design**: Professional typography and layout that reflects the book's focus on design
- **Responsive**: Works beautifully on all devices, from mobile to desktop
- **Smooth Animations**: Subtle transitions and effects that enhance the user experience
- **Living Document Indicator**: Visual cues (version badge, pulse indicator) that emphasize the evolving nature
- **Accessible**: Built with semantic HTML and accessibility best practices

## Structure

```
.

```

## Design Philosophy

The website design reflects the book's core principles:

1. **Iterative by Nature**: Version indicator and "work in progress" status
2. **Clean & Focused**: Minimal distractions, maximum clarity
3. **Evolving**: Built to easily accommodate updates and new content
4. **Professional**: Appropriate for a serious book about design practice

## Technology

Built with vanilla HTML, CSS, and JavaScript:
- No framework dependencies
- Lightweight and fast
- Easy to maintain and update
- Google Fonts: Inter (sans-serif) and Crimson Pro (serif)

## Sections

1. **Hero**: Book title, tagline, and call-to-action
2. **Teaser**: Brief overview of the book's purpose
3. **About**: Detailed description and key features
4. **Topics**: Main themes covered in the book
5. **Release Notes**: Version information and author's message
6. **Author**: About Haider Ali
7. **Footer**: Navigation and additional links

## Customization

To update content:
1. Edit `index.html` for text content
2. Modify `styles.css` for styling changes
3. Update `script.js` for interaction changes
